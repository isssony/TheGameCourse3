#	Игровая программа с графическим интерфейсом «Увернись от шариков»: пользователь играет против машины; машина бросает шарики в хаотичном порядке на протяжении определенного времени, если «шарик» попадает в игрока, игра заканчивается, если игрок продержался определенное время, происходит переход на следующий уровень.
